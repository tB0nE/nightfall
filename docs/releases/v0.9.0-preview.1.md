## Nightfall Meteor — Feature Preview 🌙☄️

Nightfall has grown quite a bit since the last preview! This one brings together host-side AI 3D, standalone browsing, multiple screens, a managed streaming host, and experimental PCVR streaming on Linux.

**This is a preview, not a stable release.** There is a lot working here, but also plenty of transitions and hardware combinations still to test. I'm putting it out alongside the demo so you can try it and help find the rough edges.

▶️ **[Watch the Nightfall Meteor Feature Preview](https://www.youtube.com/watch?v=jI8_UnwjWMw)**

### AI 3D on your PC

Meteor can generate depth on the host and send it alongside your desktop stream. Video Depth Anything adds temporal processing for video and games, while the EdgePad models provide lighter alternatives.

On my RTX 3090, the demo runs a 1440p desktop stream at 120 fps with depth updates approaching 120 Hz. This is a result from my setup, not a requirement or a promise for every GPU!

The model menu groups compatible models under your GPU or CPU. EdgePad-512 and EdgePad-256 are included and use Vulkan. Optional Video Depth Anything downloads offer NVIDIA TensorRT and generic Vulkan paths, including a smaller Vulkan option for weaker hardware. The Vulkan path opens this up to AMD GPUs too, although performance varies considerably. CPU inference remains available for experimentation.

### A browser, even without a PC

Use **Open Browser** from the welcome screen without connecting to a computer. Watch videos, open a local Plex server, browse websites, or try browser-based gaming services—and use on-headset AI 3D on the primary browser screen.

The browser includes tabs, bookmarks, optional history, ad/tracker blocking and gamepad support. YouTube and Xbox Cloud Gaming have worked in testing; website, controller and protected-content compatibility will vary.

### Multiple screens

Mix desktop monitors and browser screens in the same workspace, with up to **four screens**. Browser screens can each have their own tabs. Use the **Screens** settings to arrange the layout and the controls above a screen to add content.

Multiple desktop monitors require a compatible host; the managed Meteor-Vibepollo host includes the capture support used in this demo. You still need actual displays or a host-provided virtual-display setup—Nightfall doesn't magically create extra physical monitors.

On-headset AI inference is limited to the primary screen. A PC stream can use Meteor depth while a primary browser uses the headset's own inference.

### PCVR streaming on Linux

Start a VR application from your streamed desktop and Nightfall can hand over to an XR stream. Meteor includes a managed **Monado runtime and xrizer**; a separate WiVRN or SteamVR installation isn't required for this path.

I've tested VRChat, Moss and Half-Life: Alyx. This isn't a claim of universal game compatibility, and Proton versions and individual game settings still matter.

Your desktop stream stays available. Turn your left wrist to reveal the watch, then use its screen button to show or hide the desktop workspace inside the VR game. The gear opens dedicated PCVR settings. Closing the VR application returns to the desktop.

PCVR settings include resolution scaling, refresh rate, bitrate, sharpening and encoder-dependent foveated encoding. Some changes apply live; others take effect on the next XR session. Desktop video timing follows the active XR session and returns to your preference on exit. XR audio currently uses the retained desktop stream.

### A managed host

Meteor can download and manage **Meteor-Vibepollo**, our Nightfall-focused build of Vibepollo, instead of requiring a separately managed Sunshine-compatible host. Existing compatible hosts remain supported for desktop streaming.

The managed path includes pairing assistance, input-permission setup, USB Link integration and a stream-only host cursor size setting for supported X11 capture. The aim is to keep the Vibepollo changes focused on Nightfall integration, rather than build an unrelated competing host.

### Getting started

1. Install the **Android APK** on your Quest. It uses the existing release signing key and supports an in-place update; keep your app data and pairings.
2. Download the **Linux x86_64 Meteor AppImage**, make it executable, and run it as your normal desktop user.
3. Use an existing Sunshine-compatible host, or let Meteor install its managed Vibepollo host. Follow its pairing/input-permission prompts.
4. Connect Nightfall to the host through Meteor.
5. For PCVR, choose **Enable PCVR** in Meteor and follow the install/restart prompt. Use **Copy Steam Launch Options** at the top of Meteor's tray menu and paste the copied command into each VR game's Steam launch options. Approve the headset when Meteor prompts you; approval is remembered.
6. Launch the VR game from your desktop stream.

The Linux host needs working GPU drivers, Python 3 for PCVR, and a Linux x86_64 system with glibc 2.35 or newer. KDE has received the most testing. On desktops without a compatible tray, additional desktop integration may be needed. If FUSE is unavailable, try `APPIMAGE_EXTRACT_AND_RUN=1 ./Nightfall-Meteor-v0.9.0-preview.1-linux-x86_64.AppImage`.

### Preview limitations and feedback

- **Linux Meteor + Android APK only in this preview. Windows PCVR support comes later.** There is no Linux Nightfall client build attached.
- Quest 3 and NVIDIA have received the most real-world testing. Quest 2/3S and AMD/Intel feedback is especially useful. AMD PCVR encoding is experimental; foveated encoding and live bitrate controls depend on the encoder.
- An **intermittent host-cursor/laser misalignment after connecting** remains under investigation. We haven't established that recording causes it. Export a log while it is happening if possible; please describe the monitor selection and whether a reconnect or app resume changes it.
- Multi-screen/browser/XR transitions, standby recovery and repeated connect/disconnect cycles still need wider testing.
- Environment-preview work isn't part of this release's supported feature set.

Please include your headset, GPU, Linux distribution/session type, host, and reproduction steps when reporting issues. Nightfall's **Download Log** button exports diagnostics you can attach to a GitHub issue.
