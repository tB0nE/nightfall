## A browser inside Nightfall 🌙🌐

**This is a preview of v0.8.2, not a stable release.** I've been working on making Nightfall useful without a PC connection too: open a browser, watch something, and use the same on-headset AI 3D processing you use for your streams.

The proof of concept has turned into something quite usable. YouTube playback and fullscreen video work in testing, and I've also been able to launch Fortnite through Xbox Cloud Gaming with both Nightfall's controller gamepad mode and a connected Xbox controller. There's still plenty to test and polish, so I'd love feedback before calling this finished!

### Standalone browsing and AI 3D

Use **Open Browser** on the welcome screen—no Sunshine host or Meteor connection is needed. Browse to a website or enter search text in the address bar, use Nightfall's virtual keyboard, and enable AI 3D as usual to convert the browser's picture locally on the headset.

The browser uses Android WebView rendered into Nightfall's existing screen and AI pipeline. It isn't a separate Horizon Browser window, and the page fills the screen rather than including a toolbar in the video image.

Browser resolution can be set to **1080p or 1440p** under **Screens → Browser Res**. Close and reopen the browser after changing it. Higher resolution costs more GPU work; it doesn't force a video service to send higher-resolution video.

### Tabs and a cleaner screen

The browser controls live in a single rounded panel **above the screen**, styled to match Nightfall's menu and keyboard:

- **Top row:** browser tabs, a close cross on the hovered tab, and Add Browser on the far right. When there are more than four tabs, **Tabs** opens the full list.
- **Bottom row:** Back, Forward, Refresh/Stop, the address/search bar and a three-line settings menu. Submit an address or search with Enter on the keyboard.
- **Settings menu:** Home, Bookmarks, Privacy and Blocking.

The panel appears when you point at the controls and hides when you move away. It stays visible while you're editing the address. The welcome screen stays clean: use Open Browser to begin.

Up to **eight browser tabs** are supported, with one page active at a time. Switching away retires the old WebView and retains navigation state; background tabs aren't intended to keep playing audio or games. Website state may reload when returning to a tab. The tab workspace itself isn't restored after closing the browser.

The controls reuse the existing screen-controls composition layer rather than adding another XR layer for each tab or button.

### Bookmarks, privacy and blocking

- Save, rename, reorder and remove **bookmarks**, which persist across app restarts.
- **History is optional** and off by default. Privacy controls let you manage history and website data separately.
- Optional **ad/tracker blocking**, including filter-list updates and per-site exceptions. This is built-in filtering, not support for installing Chromium extensions, and it isn't a promise to remove every advert.
- Local HTTP websites are supported, including services such as a Plex server on your LAN. Only use unencrypted HTTP on networks you trust.

### Cloud gaming

The browser includes gamepad input for **Nightfall's Quest-controller gamepad mode** and **connected Android gamepads**, tested here with an Xbox controller. Focus the browser game and hide Nightfall's menu/keyboard before playing.

Xbox Cloud Gaming/Fortnite worked in testing, but service compatibility, DRM-protected playback, other controllers and other websites still need wider testing. This isn't a guarantee that every streaming service will work.

### What this preview does—and doesn't—include

This is the **single-screen browser milestone**. Browser tabs share one screen; they aren't separate floating browser screens. Concurrent PC streaming plus browser screens and the wider multi-screen work are still to come.

The browser has primarily been tested on **Quest 3**. Quest 2/3S browser behavior, standby recovery and repeated open/close cycles would benefit from more feedback. The APK includes the existing PC-streaming features from v0.8.1, and there are no new depth models in this preview.

**Android:** sideload the APK over the official release or release-signed DEV build without clearing settings. This is an optimized release build, not a debug APK. Preview builds carry the v0.8.2 Android version code: returning to v0.8.1 may require uninstalling the app and losing its local data, so keep that in mind before upgrading.

**Meteor is unchanged from v0.8.1.** The same 0.1.1 files are included for convenience; existing Meteor 0.1.1 users don't need to update. Meteor is optional for PC streaming and isn't needed for standalone browser AI 3D. It still requires an NVIDIA GPU for host video decoding. Windows setup requirements remain the same; see the [v0.8.1 release](https://github.com/tB0nE/nightfall/releases/tag/v0.8.1).

There is **no new Linux desktop-client build** in this browser-focused preview; the v0.8.1 Linux client remains available. This doesn't affect the Linux Meteor download above.
