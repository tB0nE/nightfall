# Nightfall 0.9.0 Preview 2 — PCVR, Multiple Screens, Windows Support

Nightfall and Meteor are coming together for 0.9.0: play PCVR games, bring
multiple desktop screens into your headset, and use Meteor on Windows or Linux.

**This is a feature preview, not a stable release.** Expect rough edges as we
test more games, GPUs and desktop configurations.

## Highlights

- **PCVR:** launch VR games through Meteor and return to your desktop stream
  when you finish. Windows supports SteamVR games, including the tested VRChat
  path, plus a Monado/xrizer path tested with Moss. SteamVR games can also launch
  directly from Steam while connected. The wristwatch brings your desktop back
  into reach during a VR session.
- **Multiple screens:** bring multiple monitors into your workspace and add
  browser screens alongside them. Windows now includes multi-monitor capture
  through Meteor's bundled Vibepollo host.
- **Windows support:** a per-user Meteor installer bundles the host and PCVR
  components, with installed-game discovery and a headset PIN pairing dialog.
  Games that need a missing SteamVR installation offer an installation prompt.
- **Matching versions:** Nightfall and Meteor now share release version numbers.
  Use the `0.9.0-preview.2` client and Meteor together for this preview.

## Getting started

1. Install the **Nightfall Android APK** on your Quest. It uses the existing
   release signing key, so you can update in place and keep app data.
2. On Windows, run the **Meteor Windows x64 installer** as your normal user.
   Choose the built-in host and PCVR setup options you need. On Linux, use the
   matching Meteor build when it is attached to this release.
3. Start Meteor and connect Nightfall through its host. Pair using the PIN
   shown in Nightfall and Meteor's **Pair headset** dialog.
4. For PCVR, open **VR Apps** and complete any headset approval prompt in Meteor.
   Install SteamVR through Steam for games that require it.
5. Launch a VR game from VR Apps. Windows SteamVR games also support direct Steam
   launch while connected; the Moss Monado/xrizer path uses the generated Steam
   launch options. On Linux, follow Meteor's PCVR setup and copied Steam launch
   options.

The Linux Meteor asset will be added separately. The Windows installer and
Quest APK are available now.

## Preview limitations and feedback

- Quest 3 and NVIDIA have received the most testing. Windows PCVR encoding
  currently requires NVIDIA/NVENC; AMD and Intel Windows PCVR are not ready.
- Windows multi-monitor capture currently supports SDR displays on one GPU.
  HDR, mixed display configurations and GPU selection need wider testing.
- SteamVR remains the Windows route for games such as VRChat whose anti-cheat
  rejects the alternative loader path. SteamVR and games are installed separately.
- Repeated game launches, desktop/PCVR transitions, standby recovery and
  multi-screen/browser layouts still need testing. SteamVR may show a Resume
  prompt when returning to a game.
- A targeted Moss bottom-edge rendering change is included; visual confirmation
  of that specific fix remains pending.
- Uninstall preserves Meteor's settings and pairing data. During development,
  an uninstall left some program files behind; complete uninstall cleanup still
  needs further verification.

Please include your headset, GPU, operating system, host and reproduction steps
when reporting issues. Nightfall's **Download Log** button exports diagnostics
you can attach to a [GitHub issue](https://github.com/tB0nE/nightfall/issues).

Thanks to everyone testing the run-up to 0.9.0!
